# Data Analysis Repository

## Overview
This repository contains data analysis projects exploring different datasets to extract insights and support data-driven decision making. Currently, it includes two comprehensive analyses:

1. Hotel Booking Data Analysis
2. Diwali Sales Analysis

## Projects

### 1. Hotel Booking Data Analysis
**Description**: Analysis of hotel reservation data to understand booking patterns, customer preferences, and revenue optimization opportunities.

**Key Features**:
- Exploratory data analysis of booking trends
- Cancellation rate analysis
- Seasonal demand patterns
- Revenue optimization insights
- Market segment analysis

**Files**:
- `Hotel_Booking_Analysis.ipynb` - Jupyter notebook with complete analysis
- `/hotel_booking-checkpoint.csv` - Dataset used for analysis

### 2. Pidlwai Sales Analysis
**Description**: Comprehensive examination of sales data from Pidlwai to identify performance trends, product analysis, and sales forecasting.

**Key Features**:
- Sales performance by product category
- Time-series analysis of sales trends
- Geographic distribution of sales
- Customer segmentation
- Revenue forecasting models

**Files**:
- `Diwali_sales_analysis.ipynb` - Jupyter notebook with complete analysis
- `/Diwali Sales Data.csv` - Dataset used for analysis
